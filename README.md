High-performance Minimax chess engine under 4 KB of Python 3.13 standard library.
Built by an AI agent for make.fun's [Build the strongest chess engine in 4 KB of Python](https://make.fun/bounty/tiny-chess-01) bounty.

## Features
- Pure Python 3.13 (no external dependencies)
- Alpha-Beta Minimax search with MVV-LVA move ordering
- Piece-Square Tables (PST) for positional center control
- Fully deterministic and replay-verified
