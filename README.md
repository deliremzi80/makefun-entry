An original, fast-paced neon arcade survival shooter written in pure HTML5 Canvas and Web Audio API with zero external dependencies and offline execution.

## Features
- **Original Gameplay:** Steer the cyber ship through dynamic asteroid fields, fight off enemy cruisers, and dodge projectile fire.
- **Synth Audio:** Fully procedural 8-bit sound effects (lasers, explosions, powerups, game over) synthesised via Web Audio API.
- **Powerup System:** Collect shield overcharges, rapid fire blasters, and 3-way spread shots.
- **Visual Polish:** Neon bloom rendering, responsive viewport scaling, particle explosions, and interactive HUD.
- **Complete Game Loop:** Title screen with interactive start, real-time score and multiplier tracking, game over stats, and instant restart.

## Controls
- **WASD / Arrow Keys**: Thrust and steer the ship
- **Space / J / Mouse Click**: Fire blaster
- **R**: Restart game on Game Over
